# 콘텐츠·포스터·편집·발표·이메일 적용 노트

아래 판단과 예시는 이 사용자용으로 새로 작성했다. 큐시트의 원문이나 원저자의 제작 방법을 인용한 것이 아니다.

## 카드뉴스·포스터

카드마다 주장이나 역할이 보이도록 하고, 장수를 채우기 위한 반복을 없앤다. 표지의 훅과 뒤의 근거가 이어지게 한다. 한 포스터에서는 한 시선 경로와 핵심 정보를 우선한다.

## 발표·매거진·인쇄

슬라이드는 말과 함께 읽는 장면, 매거진은 독자 속도로 읽는 지면으로 설계한다. 도표가 있는 슬라이드는 해석 문장을 곁들이고, 인쇄물은 판형·재단/안전 영역·폰트 포함을 출력 조건에 맞춘다.

## 이메일·뉴스레터

제목·프리헤더·도입·주요 행동이 같은 목적을 향하게 한다. 이미지 차단, 모바일 폭, 읽기 순서와 실제 링크를 확인한다. 시안 작성은 이메일 발송 권한이 아니다.

## 관찰을 결과물로 옮기기

참고한 화면의 URL과 관찰한 특징을 실제 변경에 연결한다. 예를 들어 “메뉴가 예쁨” 대신 “주요 이동과 보조 행동의 시각적 무게가 구분됨 → 현재 메뉴에서 핵심 행동을 한 단계 드러냄”처럼 설명한다. 관찰하지 않은 동작이나 보이지 않는 모바일 상태를 추측으로 채우지 않는다.

“이 자료 발표용으로 정리해줘” → 글을 카드 상자에 나열하지 않고 주장·근거·비교·결론의 장면으로 구성해 실제 슬라이드로 만든다.

## 납품

요청한 편집 원본과 렌더/내보내기 파일, 실제 확인한 페이지 및 남은 문제를 전달한다.

변경 파일·화면·출력과 확인 근거를 먼저 말한다. 미검증 상태를 짧게 밝히고, 요청이 끝났으면 형식적인 승인 질문을 붙이지 않는다.
