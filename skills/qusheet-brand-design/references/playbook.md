# 브랜딩·로고·패키지·공간 응용 적용 노트

아래 판단과 예시는 이 사용자용으로 새로 작성했다. 큐시트의 원문이나 원저자의 제작 방법을 인용한 것이 아니다.

## 로고·워드마크

서체 로고인지 심벌이 필요한지 실제 사용 조건으로 판단한다. 레퍼런스에서 비율과 대비를 분석하되 고유 형태를 베끼지 않는다. 작은 크기와 단색에서도 읽어본다.

## 패키지

정보 우선순위, 펼친 면과 접힌 면, 실물 크기와 인쇄 조건을 먼저 맞춘다. 제조 표기·성분·법정 문구가 필요한 경우 제공받은 정확한 원문을 사용하고 빈칸을 추측으로 채우지 않는다.

## 공간·환경 응용

원 사이트에서 해당 분야는 소수의 폭넓은 포트폴리오만 연결한다. 이를 공간 설계 전문 지식으로 과장하지 않는다. 안내·가시거리·위치·실제 설치 크기를 추가 자료와 현장 조건으로 확인한다.

## 관찰을 결과물로 옮기기

참고한 화면의 URL과 관찰한 특징을 실제 변경에 연결한다. 예를 들어 “메뉴가 예쁨” 대신 “주요 이동과 보조 행동의 시각적 무게가 구분됨 → 현재 메뉴에서 핵심 행동을 한 단계 드러냄”처럼 설명한다. 관찰하지 않은 동작이나 보이지 않는 모바일 상태를 추측으로 채우지 않는다.

“내 강의 브랜드 자료 통일해줘” → 기존 승인 로고·폰트를 유지하고 표지·슬라이드·프로필의 제목 위계와 이미지 처리를 같은 규칙으로 맞춘다.

## 납품

편집 가능한 원본, 실제 응용 시안과 간결한 브랜드 사용 규칙을 전달한다.

변경 파일·화면·출력과 확인 근거를 먼저 말한다. 미검증 상태를 짧게 밝히고, 요청이 끝났으면 형식적인 승인 질문을 붙이지 않는다.
