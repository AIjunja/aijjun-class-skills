# Inspected reference catalog

Review date: 2026-10-28. All32 outbound destinations were attempted in a browser;
28 rendered as public pages (including one changed-purpose site), two showed
access challenges, one was404, and one redirected to a domain sale. Page layouts
were visually reviewed via contact sheets; not every showcased site's interaction
or paid content was reviewed. Seed:
https://www.qusheet.com/1dcbc9a5-6c4e-4b80-9a48-2bd886a77fe9 .
Scope: that Landingfolio entry and its31 distinct directly related entries,
not the entire202-entry Qusheet database and not every website in each gallery.
Each Qusheet detail and outbound destination was requested; browser reading was
used to distinguish transport failures from real page access. Gallery samples,
not all showcased projects, were reviewed. Current access can change.

These are original selection notes. Reading public examples does not license
their screenshots, fonts, code, templates or assets for redistribution. Use own
assets and independently implement patterns unless exact reuse terms are verified.

## Applied selection for the Claude course

The course page uses an independently authored layout: real teaching photography
and literal offer in the first viewport, direct platform evidence, a user-driven
two-day curriculum, scoped free follow-up and working contact/portfolio links.
Landingfolio/Lapa/One Page Love inform the section/CTA decisions, Navbar/Footer
inform navigation hierarchy, and Motion/Magic UI/HOVERSTAT.ES inform short entry,
light media depth and an input-to-result demonstration. No showcased template,
code or third-party imagery was copied.

Use the reference most relevant to the next decision, not all32 on every job.
