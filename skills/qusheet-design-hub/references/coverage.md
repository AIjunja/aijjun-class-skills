## 자료와 제작 능력의 구분

이 패키지는 디렉터리의 사실 정보·출처·탐색 구조와 사용자용으로 새로 작성한 제작 워크플로다. 원문 설명·원 이미지·폰트·유료 리소스·템플릿의 복제품을 배포하지 않는다. 실제 레퍼런스 사례의 시각적 특징은 사용 시점에 해당 외부 페이지에서 확인한다.

개별 상세 페이지는 모두 읽었지만 이미지 픽셀/동영상/스크린샷의 전수 시각 해석이나 OCR은 수행하지 않았다. 외부 201개 사이트의 모든 하위 글·화면·파일도 전수 수집하지 않았다. 외부 기본 URL의 생존 여부·로그인·유료 범위·가격·현재 라이선스를 일괄 검증하지 않았다. `external_verified`와 `license_verified`는 모두 false다. 미열람 외부 링크를 검증된 근거로 인용하지 않는다.

자료의 오래된 제품 수량·업데이트 주기·가격은 스킬에 고정하지 않았다. 상세 페이지 연결과 분류를 읽은 사실은 해당 도구를 설치·실행했거나 디자인 품질을 검증했다는 의미가 아니다.

## 수집 방식

Firecrawl 크레딧 부족 후 공개 웹 조회와 브라우저로 접근했다. 사이트 robots.txt는 공개 경로를 허용하고 /_private/를 제외한다. 로그인·비공개 경로·결제·가입 없이 공개 HTML에 포함된 데이터만 읽었다. 공개 페이지 데이터의 설정·사용자 기록·인증 필드는 보관하지 않았다.

검색·스킬 본문은 네트워크나 유료 API 없이 사용할 수 있다. 레퍼런스의 현재 동작 확인은 별도 읽기 작업이다.
