# 아이콘·일러스트·3D 에셋 적용 노트

아래 판단과 예시는 이 사용자용으로 새로 작성했다. 큐시트의 원문이나 원저자의 제작 방법을 인용한 것이 아니다.

## UI 아이콘

한 계열에서 필요한 의미를 먼저 찾는다. 픽셀 크기가 같아도 시각적 무게가 다를 수 있으므로 실제 버튼/리스트에 넣어 비교한다.

## 브랜드·일러스트

브랜드 로고를 일반 장식 아이콘처럼 다시 그리거나 색을 바꾸지 않는다. 설명용 삽화는 인물·시점·배경·명암이 같은 언어인지 확인한다.

## 3D·움직이는 아이콘

카메라 각도, 광원, 재질, 그림자와 배경을 맞춘다. 작은 화면에서 복잡한 디테일이 사라지는지 보고, 애니메이션이면 정지 대체도 준비한다.

## 관찰을 결과물로 옮기기

참고한 화면의 URL과 관찰한 특징을 실제 변경에 연결한다. 예를 들어 “메뉴가 예쁨” 대신 “주요 이동과 보조 행동의 시각적 무게가 구분됨 → 현재 메뉴에서 핵심 행동을 한 단계 드러냄”처럼 설명한다. 관찰하지 않은 동작이나 보이지 않는 모바일 상태를 추측으로 채우지 않는다.

“아이콘들이 제각각이야” → 기존 계열을 정하고 실제 사용 아이콘을 같은 스타일로 교체한 뒤 버튼과 목록에서 비교한다.

## 납품

실제로 연결한 에셋/컴포넌트, 출처와 확인한 사용 조건, 화면 적용 결과를 전달한다.

변경 파일·화면·출력과 확인 근거를 먼저 말한다. 미검증 상태를 짧게 밝히고, 요청이 끝났으면 형식적인 승인 질문을 붙이지 않는다.
