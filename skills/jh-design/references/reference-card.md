# Reference Card

Create one card per selected reference.

```markdown
## Reference [A]

- Source URL or local path:
- Checked on:
- Screen or section:
- Project type:
- Intended user:
- Why it matches:

### Adapt
- Information order:
- Layout or grid:
- Typography hierarchy:
- Spacing rhythm:
- Color roles:
- Interaction or state behavior:
- Motion, if functional:

### Do not copy
- Brand identifiers:
- Proprietary wording or data:
- Distinctive imagery or illustration:
- Layout details that conflict with this workflow:

### Translation into this project
- Current content mapped to the pattern:
- Brand identity rule that transforms the reference:
- Hook or copy implication:
- Motion or media implication:
- Mobile change:
- Accessibility or usability correction:
- Risk to verify:
```

## Three-Reference Synthesis

After writing the cards, summarize:

```text
Structure comes from:
Interaction comes from:
Visual tone comes from:
Hook/copy energy comes from:
Motion/media behavior comes from:
The final screen will not copy:
```

If all three references suggest different densities, audiences, or interaction models, the selection is incoherent. Replace one before implementation.
