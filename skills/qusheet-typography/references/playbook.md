# 한글·영문 타이포그래피 적용 노트

아래 판단과 예시는 이 사용자용으로 새로 작성했다. 큐시트의 원문이나 원저자의 제작 방법을 인용한 것이 아니다.

## 화면 글자

웹폰트 로딩 전후의 폭 변화, 한글 폴백, 버튼·레이블 길이, 숫자 정렬을 확인한다. 고정 높이 안에서 행간이나 이탤릭 하단이 잘리지 않게 한다.

## 표지·포스터·슬라이드

한 화면의 우선 문장을 정하고 강조를 크기·굵기·위치로 표현한다. 문구를 짧게 줄일 때 근거와 핵심 의미를 보존한다. 모든 제목을 같은 크기나 같은 두 줄로 강제하지 않는다.

## 서체 사용례·로고

폰트 이름을 알아내는 것과 사용 권리를 얻는 것을 구분한다. 브랜드가 커스텀한 자형일 수 있으므로 유사한 폰트명을 확정 정보로 바꾸지 않는다.

## 관찰을 결과물로 옮기기

참고한 화면의 URL과 관찰한 특징을 실제 변경에 연결한다. 예를 들어 “메뉴가 예쁨” 대신 “주요 이동과 보조 행동의 시각적 무게가 구분됨 → 현재 메뉴에서 핵심 행동을 한 단계 드러냄”처럼 설명한다. 관찰하지 않은 동작이나 보이지 않는 모바일 상태를 추측으로 채우지 않는다.

“표지 글자가 답답해” → 승인 폰트는 유지하고 문구의 위계·행간·줄 길이·이미지와의 여백을 비교해 고친다.

## 납품

적용된 폰트/출처와 역할별 조판 값, 실제 문구가 들어간 결과물을 전달한다.

변경 파일·화면·출력과 확인 근거를 먼저 말한다. 미검증 상태를 짧게 밝히고, 요청이 끝났으면 형식적인 승인 질문을 붙이지 않는다.
